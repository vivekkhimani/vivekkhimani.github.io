## A subhead if it needs one

Code is highlighted at build time, so nothing ships to the reader:

```python
def example():
    return "no highlighting library required"
```

To publish: move this file to `_posts/` and rename it `YYYY-MM-DD-some-slug.md`.
The date in the filename sets the post date. The URL is `/writing/some-slug/`,
with no date in the path.

Anything left in `_drafts/` is never built, so half-finished work is safe to commit.
